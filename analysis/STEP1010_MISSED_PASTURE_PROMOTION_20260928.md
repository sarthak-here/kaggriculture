# Step1010 missed-pasture recovery promotion

## Mechanism

A day-1 weed can block the common route's pasture at `(4,2)`. Step1010 digs
the weed, but at step 69 it later attempts `PLACE COW` on the empty tile,
followed by ineffective `CARE` and `PASS`. The candidate recognizes this exact
observable state and substitutes `BUILD_PASTURE`, `PLACE COW`, `CARE` across
steps 69-71. All other states return the frozen Step1010 BRUNCH parent action.

The parent route audit found the same `PLACE COW` / `CARE` / `PASS` sequence at
step 69 in 40 of its 41 route tables, so the intervention repairs a shared
opening defect rather than one late shop route.
